BOM Dashboard Generator

Turns a BOM table into the self-contained dashboard. Nothing leaves this page.

1 · Load the BOM

Drop an .xlsx, .csv or .tsv file here, or click to choose
or paste below — from Excel, or straight from the web page
Accepts three things: a workbook (.xlsx), a delimited file (.csv / .tsv), or pasted text.
Columns are matched by header name — Module, Supplier Part No., Item Description, Manufacturer, Manufacturer Part No., Total Qty, Status. Extra columns and any column order are fine.
Web copies: when the site wraps a cell over several lines, the fragments are rejoined automatically and the count is reported below.

2 · Options

Comma-separated module numbers
v0.01, v0.02 … or v1.00 at a major release
Never overwrite — keep the version in the name
